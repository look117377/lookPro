# lookPro

A modern project scaffold for building and shipping software quickly.

## Overview

`lookPro` is a starter repository intended for rapid development. It provides a clean foundation for building applications with a clear structure and easy onboarding.

## Project Structure

```text
lookPro/
├── README.md
├── .gitignore
├── package.json
├── src/
│   ├── app/
│   ├── components/
│   ├── pages/
│   └── utils/
└── public/
```

## Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — run the production build locally
